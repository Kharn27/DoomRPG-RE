## Contrat exact conservé

Ancien `__wrap_EspAssetPack_residentEnd()` lié en production : en TRACE seulement, `reportIoSample("resident-end")` puis `invalidatePhysicalBaseline()` **avant** `__real_EspAssetPack_residentEnd()`. Ce préambule devait s'exécuter même si la vraie API retournait `0` pour `openReady`. En INFO, le wrapper n'avait aucun effet observable hors appel du vrai propriétaire.

ARCH-RC3 retire uniquement le flag `-Wl,--wrap=EspAssetPack_residentEnd`, les alias `__wrap_`/`__real_` correspondants, et appelle désormais la petite interface native C permanente `EspAssetPackIoProbe_beforeResidentEnd(void)` depuis `EspAssetPack_residentEnd()`, **avant** le test `if (openReady)`. La fonction du propriétaire conserve tels quels le retour de refus, les drapeaux `residentLargeRangeEnabled`/`residentEnabled`, `resetPhysicalState()`, le `free(residentCache)` conditionnel et `clearMapFlashRuntime(true)`. Le hook TRACE vit dans `esp_asset_pack_perf_probe.cpp` et partage l'ABI de `esp_asset_pack_io_probe.h` introduite en RC2. Aucune allocation ajoutée, nouveau propriétaire, source ZIP, audio, gameplay, renderer, LCD ou framebuffer modifiés.
