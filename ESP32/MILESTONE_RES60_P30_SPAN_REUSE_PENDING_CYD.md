# RES60-P30 — row-local material reuse (candidate)

P29 CYD functional PASS with mixed timings. The per-pixel sampler scans both the logical descriptor array and LRU slots even for contiguous samples of the same logical material. P30 reuses only the last row-local descriptor and cache slot in 192-wide preview, refreshes exact cache age and hit count per pixel, and falls back to the existing acquisition path on each logical transition. No change in PAK read order, palette alias semantics, raster coordinates, payload ownership or LCD. One additional transient 32-bit counter, no permanent payload. Classic 160 keeps old sampler; compile-time P30=0 baseline remains available. The host oracle compares all 9/12 material eviction counters and independent exact pixels/canaries against P29, with the frozen SDL historical inverse preserved. Actual CI and CYD pending.
