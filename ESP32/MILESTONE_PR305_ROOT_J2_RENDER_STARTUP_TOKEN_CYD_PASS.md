## Frontière modifiée

`EspRenderStartupBridge_start(DoomRPG_t* root, int preRenderReady)` vérifie le token processus **explicitement transmis** par `ESP32/src/main.cpp`, et conserve les contrôles préalables : `preRenderReady`, Render et Canvas existants, PAK preflight, framebuffer PlatformVideo partagé, pitch et palettes valides. `render_startup_bridge.c` n'utilise plus `extern doomRpg` ; `esp_render_startup_bridge.h` forward déclare le type, sans allocation de mémoire. Le singleton processus `DoomRPG_t` de 1 B et les autres contrats fatal/teardown demeurent intentionnellement, comme SDL et compatibilité ; pas de changement rendu/PI/O, shapeData ou mediaTexels. Le test `root_j2_render_startup_token_host.py` remet exactement les **trois fichiers modifiés** sur leurs blob Git du main de départ puis exerce le corps C réel, fail-closed, état de tentative unique.
